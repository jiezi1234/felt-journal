# 毛毡生活手账微信小程序

原生微信小程序，基于既有 `front/` 设计实现 P0：首页、每日毛毡板、拍照/相册添加、四角布置、记忆详情、月历回顾及完整板面导出。记录与图片长期保存在本机，无账户与云同步。

微信开发者工具打开本目录，入口为 `miniprogram/pages/index/index`。原有 `front/`、云函数和示例页面保留，QuickStart 不再作为业务入口。

底部导航为“主题板 / 今天 / 月历时光”：今天居中，以黑色胶囊按钮突出当天毛毡板这一主要功能；主题板持续收集不同日子的同类记忆，月历回顾每日手账。启动时默认进入今天。主导航采用微信自定义 tabBar 和 `switchTab`，保留页面与月历月份。首页右下角圆形“＋”和“布置”在原页面上打开卡片，选图、处理、布置及文字分类编辑均在卡片内完成；关闭后刷新今日板。底色与纹理默认收起，通过“板面与纹理”抽屉选择。首页仍保留照片详情与完整作品分享入口。
