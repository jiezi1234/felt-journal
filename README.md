# 毛毡生活手账微信小程序

原生微信小程序，基于既有 `front/` 设计实现 P0：首页、每日毛毡板、拍照/相册添加、四角布置、记忆详情、月历回顾及完整板面导出。记录与图片长期保存在本机，无账户与云同步。

微信开发者工具打开本目录，入口为 `miniprogram/pages/index/index`。原有 `front/`、云函数和示例页面保留，QuickStart 不再作为业务入口。

首页、毛毡板浏览页和月历页已按原稿恢复固定底部导航：“今天 / 毛毡板 / 月历时光”，包含本地图标、选中状态和底部安全区。主导航采用微信自定义 tabBar 和 `switchTab`，切换时保留页面、画布、滚动位置与月历月份，避免反复重开页面造成白屏。今日板标签为浏览页，编辑仍进入独立日期页；分类查找由首页和月历入口进入。

已接入 P1-01 至 P1-07：布局撤销重做、图层调整、图片裁剪修正、6 色与 3 种纹理、分类/月筛选、完整作品图片分享，以及主题板与跨板复用。首页“主题板”可创建不同主题，复用各日期的记忆，布局独立保存。板上的“仅移除摆放”保留照片和文字；详情的“彻底删除记忆”才删除所有板上的引用。旧记录读取不写入，首次成功修改原子升级为内部 v2 格式。

每日板和主题板均可导出并分享到微信，由用户在微信面板中选择发送对象；手机实际发送与接收方查看仍待验收。

开发者工具自动化端口开启后，可依次运行 `npm run test:e2e`、`npm run test:filters`、`npm run test:share`、`npm run test:themes`、`npm run test:navigation`。100 项自动测试、9 个页面路由检查通过；本次导航修复重新通过导航专项和完整添加/编辑/导出/月历回归。这些模拟器测试会临时隔离并最终恢复存储，运行期间不要并行执行、编辑或重新编译小程序。分享专项使用接口替身，不实际向好友发送或写入相册。详细范围与真机待办见 [P1 开发与验收](docs/P1开发与验收.md)。

开发者工具现已接通本机真实提取服务，手机预览已由用户确认拍照、编辑恢复、详情替换/删除及相册保存通过。手机真实主体提取仍缺 HTTPS 部署与微信合法域名；复杂照片质量和部分系统异常场景尚待最终验收，不能宣称全部 P0 已验收或上线。

本机 Python 服务运行后，使用 `npm run dev:extraction` 开启开发者工具专用连接；手机与发布版不会使用该回环调试开关。HTTPS 部署文件位于 `backend/compose.yaml` 和 `backend/Caddyfile`，填写服务器域名后再实际部署。

2026-10-15：腾讯云 2 核 4 GB Ubuntu 服务器已完成 Docker 内部部署，动物、食物、植物真实抠图和容器重启后的恢复均通过；修复了只读容器中 Numba 缓存不可写导致首次抠图 503 的问题。默认只开放服务器回环端口，公网 HTTPS 通过 `public` profile 单独启用。ICP备案尚未提交，域名解析、证书、微信合法域名及手机正式提取仍待完成；详见后端文档的服务器验收记录。
