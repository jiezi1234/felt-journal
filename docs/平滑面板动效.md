# 添加记忆与更多的平滑面板

参考 [Sudoku a Day 的 Smooth sheet transitions](https://designspells.com/spells/smooth-sheet-transitions-in-sudoku-a-day)。实现依据网页录屏的逐帧观察；没有原应用安装包或源码，本次没有使用 REA，也不将下面的适配参数称为原版参数。

## 动效拆解与适配

| 层次 | 小程序实现 |
| --- | --- |
| 前后层级 | 首页背景缩至 96%、下移 8px、圆角 28px；遮罩同步淡入。关闭时连续恢复。 |
| 面板进出 | 底边固定，420ms 从底部升起，220ms 退出；退出结束前保留面板及遮罩，拦截重复操作。 |
| 内容导航 | 更多、版面与纹理、记忆库、重命名和删除确认共用一个面板外壳。360ms 改变高度，内容水平位移并淡化；返回时反向恢复菜单。 |
| 添加记忆 | 日历板和主题板都打开原页记录卡片，选图区与处理区使用同一外壳，350px → 620px 平滑伸展。取消选图回到来源区。主题板保留从现有记忆添加的入口。 |
| 画布安全 | 延续先准备并解码快照、再隐藏原生画布、最后打开面板的顺序。静态菜单和记录卡片冻结原生绘制；版面与纹理保留实时预览。 |
| 记忆库 | 浏览组件支持内嵌模式，使用外层面板的遮罩与外壳；返回菜单后保留组件实例及列表位置。记忆详情关闭后回到原库。独立弹出和物体归档模式保留原有行为。 |

使用 WXSS 缓动曲线近似录屏中的柔和收尾，没有添加额外动画依赖，也没有对实时画布施加模糊滤镜。面板高度有明确上限，受可用窗口高度约束；短屏内容在面板内部滚动。内嵌记忆库将键盘后的可用高度传给外层面板。

## 几何与生命周期

- 隐藏版面选择内容时，直接隐藏纹理样片的原生 Canvas 并停止绘制，避免原生层穿过 `opacity`、`visibility`，显示到菜单或记忆库上方。
- 背景缩放仅影响展示。毛毡板通过 `NodesRef.fields` 的 `computedStyle` 读取布局宽高，避免将缩放后的包围盒写回原生画布，导致反复缩小或贴纸布局变化。
- 开始贴纸布置时，背景用 420ms 恢复原尺寸；440ms 后重新测量落点。现有剥离阶段共 500ms，因此测量在飞行前完成。专项检查实际飞行目标与最终板上物体包围盒相差小于 1px。
- 离开页面时取消未完成的关闭回调，避免旧回调影响重新打开的面板。保存失败、记忆详情覆盖、记忆库操作进行中均阻止穿透导航或关闭。
- 主题板的重命名使用同一面板中的子页面，沿用水平切换和高度动效；返回、取消或保存成功均回到更多菜单。保存失败保留输入和错误信息，键盘收起时恢复面板高度。删除主题板也在同一底部面板内确认，展示待删除板名及保留照片、文字的说明；返回、取消或点击遮罩回到更多菜单。确认成功后沿用面板退出动效，再显示下一块主题板或空状态；失败在确认页显示错误并允许重试，不另开页面或系统弹窗。

## 验证

```powershell
npm test
npm run check
.\scripts\compile-wechat.ps1
npm run test:sheets
node tests/menu-layer-e2e.js
```

`test:sheets` 在微信开发者工具中依次验证两种板面的更多菜单、版面高度与底边、纹理、内嵌记忆库、详情返回、重命名、删除确认及取消返回、最后一块主题板删除后的空状态、记录卡片进出、处理区伸展和真实贴纸飞行。处理结果使用本地固定数据，不上传照片、不调用真实相机或提取服务。测试隔离并逐键核对恢复原有存储，截图与报告写入 Git 忽略的 `artifacts/smooth-sheet/`。

`menu-layer-e2e` 审计静态菜单覆盖期间的原生绘制与导出，防止画布闪到面板上层。真机帧率、系统相机/相册、物理小屏和系统键盘仍需手机复核；模拟器检查不代替发布与真机验收。
