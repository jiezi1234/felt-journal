# 微信图片分享

2026-10-26：分享内容为完整毛毡板 PNG。每日板和主题板使用同一套流程，分享预览中的颜色、纹理和物件就是发送的图片，最长边为 1800 px，保持来源板面比例。只改变本次分享样式，不写回原板面。

## 使用方式

1. 打开板面的分享卡片，等待图片生成，可点击预览查看大图。
2. 点击“分享到微信”，在微信原生面板中选择朋友或朋友圈。
3. 微信不提供图片分享面板时，按钮改为“打开图片分享”。点击后长按大图，选择发送给朋友。
4. 面板没有朋友圈选项时，点击“保存到相册”，再在微信朋友圈选择该图片发布。保存后界面会显示这一步提示。

分享面板临时失败时可重试，也提供“打开大图，长按分享”入口。相册权限被拒绝时仍可使用直接分享和大图预览。取消不会显示失败或发送成功；原生接口返回成功仅代表调用完成，不代表朋友已收到图片。

## 兼容与状态

- `wx.showShareImageMenu` 从基础库 2.14.3 起支持；官方说明从 3.8.2 起支持分享到朋友圈。具体选项以微信客户端提供的面板为准，因此保留相册发布入口，不伪造直接跳转朋友圈的能力。
- 每次打开卡片检查接口能力。接口存在但返回不支持时，本次卡片会记住该结果，下一次点击走预览，不反复调用失败接口。
- 原生面板或预览都在用户点击的同步调用链中启动；接口异步报错后不自动弹出另一个原生界面，等待新的点击。
- 大图预览显式设置 `showmenu: true`，使用与分享预览相同的文件。直接分享显式设置 `needShowEntrance: false`，不附带无法供接收方读取的本地记录链接。
- 生成、保存、分享和打开预览互斥，防止重复点击。图片文件失效时提示重新生成；页面卸载后的回调不更新界面。

API 依据：[微信官方接口类型及说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)（`ShowShareImageMenuOption`、`showShareImageMenu`、`PreviewImageOption`）。

## 分享图标点击修复（2026-10-26）

毛毡板上移 42 px 后，原生 Canvas 的透明夹子预留区覆盖了右上角分享图标。本次开发者工具实测：分享按钮范围为 y=179.625–223.625，画布从 y=193.458 开始，按钮中心位于画布内。点击会被画布处理为板面空白点击，未进入分享入口。

修复后，标题操作行在普通渲染层中位于画布上方；原生画布接到顶部透明区域的点击时，会按实际按钮边界交给分享或主题选项。滑动、取消、弹层期间和切换板面后的过期回调均不触发操作。毛毡板的位置、尺寸和导出构图不变。
