## 1. 产品目标与界面原则

每天为用户提供一块毛毡板，将照片自动提取主体后变成记忆物件。用户可以布置物件，并通过完整毛毡板回顾当天生活。

核心闭环：**上传照片 → 自动提取主体 → 放回原毛毡板 → 点击图片周围按钮布置 → 保存 → 回看 / 导出**。

界面设计遵循以下原则：

1. 板面是回顾生活的主画面，照片列表只承担辅助查找作用。
2. 浏览与编辑明确区分，浏览过程中不得意外修改布局。
3. 记录入口清楚，文字和分类允许跳过。
4. 第一版优先完成每日记录，不展示未上线功能的入口。
5. 保存状态可见；处理完成、保存成功和导出成功使用不同反馈。

## 2. 第一版统一建议

历史回顾采用月历形式已由用户明确：默认展示当月，每个日期格展示当天板面上的前两个物件，点击日期查看完整毛毡板。用户进一步明确：选中图片后在图片周围显示缩放与旋转图标，点击进行调整，取消底部大小与角度滑杆；上传照片后自动提取主体，并直接放回原板面进行布置。其余待确认项见第 12 节。

| 事项       | 本文采用的建议口径                                    |
| -------- | -------------------------------------------- |
| 浏览模式查看详情 | 单击在原页打开记忆卡片；长按进入编辑并选中物件                    |
| 编辑模式查看详情 | 单击仍打开记忆卡片；长按切换选中物件，再使用缩放、旋转或拖动           |

## 3. 页面与导航结构

2026-10-14 导航还原与白屏修复：参照前端原稿，在首页、毛毡板浏览页、月历页固定显示“今天 / 毛毡板 / 月历时光”，带对应图标、当前项高亮和安全区留白。三个主入口使用微信自定义 tabBar 和 `switchTab`，保留页面实例、画布、滚动位置与月历月份，替换此前每次关闭并重新打开页面的 `reLaunch`。“毛毡板”主入口为独立的今日浏览标签；编辑打开日期子页，保存后返回刷新同一块板。从月历打开历史板仍保留日期，返回恢复原月份；点击历史板底栏的“毛毡板”会回到今日板。编辑、图片处理、详情、筛选和导出等子流程采用原稿的专注页面。主导航切换不累加返回栈，连续点击当前标签不重开页面；今日板重新显示或跨天时更新日期。

第一版包含四个主要页面。照片选择、图片处理、文字输入和板面设置使用原生能力、弹窗或轻量子流程承载。

| 页面     | 主要目的            | 进入方式                  | 离开方式            |
| ------ | --------------- | --------------------- | --------------- |
| 首页「今天」 | 展示今日板面，快速开始记录   | 打开小程序 / 返回首页          | 进入毛毡板、记录流程或时光回顾 |
| 毛毡板    | 浏览整块板面与编辑物件     | 首页预览、继续布置、历史月历、添加物件成功 | 返回来源页面或进入记忆详情   |
| 记忆卡片   | 查看照片、翻转查看和编辑说明 | 浏览和编辑时均单击物件                 | 关闭后回到原板面     |
| 时光回顾   | 通过月历查找某一天       | 首页历史入口                | 返回首页或进入某日板面     |

主要流转：

```text
首页「今天」
├─ 记录今天 → 选择并上传照片 → 自动提取主体 → 保存并放回原板 → 选中物件进行布置
├─ 继续布置 → 今天的毛毡板编辑模式
├─ 点击今日预览 → 今天的毛毡板浏览模式
├─ 点击最近记录 → 对应日期的毛毡板浏览模式
└─ 时光回顾 → 当月日历（每日最多两个物件预览） → 对应日期的毛毡板浏览模式

毛毡板浏览模式
├─ 点击物件 → 记忆详情 → 返回原板面
├─ 编辑 → 编辑模式 → 完成并保存 → 浏览模式
└─ 导出 → 图片预览 → 保存到相册
```

## 4. 首页「今天」

### 4.1 页面目标

让用户一眼看到今天的记录状态，并可以立即添加一件生活记忆。

### 4.2 功能区域

| 区域     | 展示内容                   | 用户操作与响应             | 优先级 |
| ------ | ---------------------- | ------------------- | --- |
| 日期区    | 今天的日期                  | 日期随首页重新进入或恢复前台而检查更新 | P0  |
| 今日板面   | 当天板面的完整缩略预览            | 点击进入浏览模式            | P0  |
| 主操作    | 空板显示“记录今天”；有物件显示“继续布置” | 前者进入照片选择，后者进入编辑模式   | P0  |
| 最近记录   | 最近非空板的缩略图与日期           | 点击进入对应板面浏览模式        | P0  |
| 历史入口   | “时光回顾”                 | 进入当月日历              | P0  |
| 本地保存提示 | 首次成功记录后提示数据保存方式        | 明确告知卸载或清理相关数据可能造成丢失 | P0  |

### 4.3 页面状态

- **今日空板**：显示默认毛毡板和“记录今天”，可使用简短引导文案。
- **今日已有记录**：显示最新板面预览和“继续布置”。
- **没有历史记录**：最近记录区域显示轻量空状态，或隐藏缩略列表。
- **加载中**：显示占位或加载反馈，避免将尚未加载的记录误显示为空板。
- **加载失败**：提示重试，不覆盖已有记录。

### 4.4 每日板规则

- 以设备本地日期识别“今天”，不依赖后台每天创建空记录。
- 当天没有数据时先展示默认空板；首次添加物件或修改板面设置后持久化。
- 月历始终展示当月全部日期；未保存过内容或设置的日期显示空白日期格，不额外创建板面记录。
- 仅修改设置但没有物件的板可保留数据；月历显示日期但不展示物件预览，点击后加载已保存的板面设置。
- 删除最后一个物件后，该板按空板处理。
- 跨零点仍在编辑时，继续编辑原日期；返回首页后展示新日期。
- P0 不提供历史空白日期补记，不处理跨时区历史迁移。

## 5. 毛毡板页面

### 5.1 共用布局

| 区域    | 功能                                      |
| ----- | --------------------------------------- |
| 顶部    | 返回、所属日期、模式操作；编辑时显示保存状态                  |
| 中部    | 固定比例的毛毡画布，完整展示板面与物件                     |
| 底部    | 根据模式提供编辑、添加、导出等操作                       |
| 选中工具区 | 图片周围显示放大、缩小及左右旋转图标；下方仅保留记忆与删除操作，不显示变换滑杆 |

采用普通手机竖屏作为首轮设计基准。画布完整适配屏幕，工具不得长期遮挡主要内容。画布比例在视觉设计阶段确认，并保持浏览、编辑和导出一致。

### 5.2 浏览模式

- 展示完整板面，默认不显示控制框和编辑工具。
- 单击物件在原页打开记忆卡片。
- 长按物件进入编辑并选中，也可点击“编辑”进入编辑模式。
- 点击“导出”进入导出流程。
- 拖动和轻微滑动不得修改物件位置。
- P0 不提供板面双指缩放。

### 5.3 编辑模式

| 功能   | 操作方式               | 响应与规则                         |
| ---- | ------------------ | ----------------------------- |
| 添加物件 | 点击拍照或相册            | 上传后自动提取主体，在原板面显示进度，完成后直接插入并选中 |
| 选中物件 | 长按物件约 650ms         | 显示选中框及图片四角的缩放、旋转图标，松手不弹卡片 |
| 移动物件 | 拖动选中物件             | 更新位置，手势结束后保存                  |
| 缩放   | 点击图片周围的放大 / 缩小按钮   | 按固定步长调整大小，每次操作后自动保存           |
| 旋转   | 点击图片周围的顺时针 / 逆时针按钮 | 按固定角度调整，每次操作后自动保存             |
| 查看记忆 | 单击物件                   | 原页弹出卡片，关闭后保留原编辑状态             |
| 删除   | 点击“删除记忆”           | 弹出二次确认，确认后删除对应记忆及摆放           |
| 板面设置 | 点击板面设置入口           | P0 提供基础背景颜色选择；更多颜色和纹理为 P1     |
| 取消选中 | 点击画布空白区域           | 隐藏选中工具                        |
| 完成   | 点击“完成”             | 保存成功后进入浏览模式；失败时保留编辑状态         |

基础颜色的具体数量由视觉设计确认，默认颜色应始终可用。图层顺序需要持久化，但 P0 不提供用户手动置顶、置底工具；新物件默认放在最上层。

### 5.4 操作边界

- 物件不得完全移出画布；缩放有合理的最小值和最大值。
- 长按编辑只在按住时移动未超过 6px 时触发；提前滑动取消长按。长按生效后可继续拖动物件，拖动结束不弹卡片。未选中物件的滑动不改变布局。
- 缩放、旋转作用于当前选中物件，不影响整块板面。
- 图片四角建议布局：左上逆时针、右上顺时针、左下缩小、右下放大；旋转后图标保持正向，便于识别。
- 点击步长建议为大小 10%、角度 15°，具体数值经原型验证确认。
- 取消选中后隐藏四角按钮；缩放与旋转不使用底部滑杆。
- P0 以点击图标为主，不依赖双指手势完成缩放或旋转。
- 控制按钮需要足够点击区域，并避免在物件靠近画布边界时被遮挡或裁掉。
- 布局变化不得解除物件与记忆的关联。
- 新物件使用默认位置、尺寸和角度；保存成功后进入编辑模式并选中。
- 物件重叠时优先选中最上层命中的物件。
- P0 不提供锁定、对齐、吸附、批量选择和通用撤销工具。

### 5.5 保存反馈

| 状态   | 建议界面文案   | 行为              |
| ---- | -------- | --------------- |
| 正在保存 | 保存中…     | 保留当前画面，防止重复提交   |
| 保存成功 | 已保存      | 更新板面预览与历史数据     |
| 保存失败 | 保存失败，请重试 | 保留可恢复的编辑内容并提供重试 |

拖动结束、每次点击缩放 / 旋转按钮或修改设置后自动保存；点击完成与离开编辑器前补充保存。

“完成”表示保存并退出编辑，不表示放弃修改。P0 不提供恢复到本次进入编辑前的状态。存在未保存内容时离开，应提示重试或确认放弃未保存部分，不能默认丢弃。

## 6. 添加记忆流程（上传后自动提取）

### 6.1 选择并上传照片

| 功能   | 要求                    |
| ---- | --------------------- |
| 拍照   | 拍摄一张照片，确认后上传并立即开始主体提取 |
| 相册   | 选择一张照片，确认后上传并立即开始主体提取 |
| 取消选择 | 回到原板面，不产生新记忆          |
| 权限失败 | 说明原因，提供重新尝试或设置引导      |

P0 每次添加一张照片。添加开始时固定目标 Board 和日期；处理中跨零点或从历史板发起，不得改放到今天的板。

### 6.2 原板面中的自动提取状态

上传成功后自动开始主体提取，不进入独立裁剪、背景处理或文字必填页面。原毛毡板保留在背景中，使用轻量浮层显示进度。

| 状态        | 界面反馈                          | 可执行操作               |
| --------- | ----------------------------- | ------------------- |
| 上传中       | 显示上传反馈                        | 取消；防止重复提交           |
| 自动提取中     | 显示原图与提取效果示意，提示完成后回到当前板        | 取消处理                |
| 提取成功且保存成功 | 保存原图、提取图与默认摆放，关闭浮层，直接在原板选中新物件 | 移动、点击四角按钮缩放和旋转、填写记忆 |
| 提取失败      | 明确提示没有成功生成物件                  | 重新提取、使用原图继续、取消      |
| 保存失败      | 区分于提取失败，保留当前结果并提示重试           | 重试保存、取消             |

新物件自动设置初始位置和尺寸。原有物件的位置、尺寸和角度不因添加而改变；新物件位于最上层。用户直接在原板上布置，不再点击“下一步”或“放到毛毡板”完成插入。

### 6.3 图片与记忆内容

- 保留原始照片；自动提取生成独立的主体图片，不覆盖原文件。
- 提取成功后应用统一的基础边缘与柔和阴影。
- 提取失败时，用户可明确选择保留原图，不得把失败结果提示为提取成功。
- 新记忆默认文字为空、分类为“未分类”，不阻断插入流程。
- 用户在板上选中物件后，通过“查看 / 写下记忆”进入详情补充文字和分类。
- 提取成功但主体效果不合适时，可以在记忆详情替换照片，重新触发自动提取。
- 手动裁剪、复杂主体精修及多种艺术风格放入后续范围；基础自动提取已经进入 P0。

### 6.4 中断与保存一致性

- 上传、提取或保存尚未完成时，不能显示“记忆已保存”。
- 取消处理不生成正式记忆，也不改变原有板面。
- 处理期间离开时说明尚未完成，并取消当前任务；过期回调不得继续插入物件。
- 图片处理草稿自动恢复不属于 P0。
- Memory 与默认 Placement 一并保存，避免已保存但无法找到的记忆。
- 替换图片失败或取消时继续保留旧照片、旧物件与原摆放；成功后保留所属 Board、位置、尺寸、角度与图层顺序。

## 7. 记忆详情页面

### 7.1 信息与操作

| 区域   | 展示 / 功能           |
| ---- | ----------------- |
| 顶部   | 返回与页面标题           |
| 照片区  | 展示原始照片，支持查看大图     |
| 物件预览 | 展示当前处理后的图片        |
| 内容区  | 用户文字；为空时不显示冗余占位正文 |
| 元信息  | 所属日期与分类           |
| 编辑操作 | 修改文字、分类，或替换照片     |
| 删除操作 | 二次确认后删除记忆         |

所属日期在 P0 只读，不支持从详情迁移到其他日期。

### 7.2 编辑规则

- 修改文字和分类后，明确保存结果。
- 替换照片上传后自动提取主体；成功后更新原板上的同一物件，不创建重复记忆。
- 新图片成功保存后再替换旧图片引用；处理取消或保存失败时继续使用原内容。
- 替换后保留原有位置、角度和图层顺序，尽量保持原有展示尺寸。
- 返回板面时恢复进入详情前的浏览 / 编辑模式。

### 7.3 删除确认

建议文案：

> 删除这条记忆？应用内保存的照片、文字及板上的物件会一并删除，删除后无法恢复。不会删除手机相册中的原照片。

- 按钮：“取消”“删除”。
- 取消不改变任何内容。
- 删除成功后返回所属板面，更新首页预览与历史记录。
- 删除失败时提示重试，不提前从界面移除记录。
- 删除最后一条记忆后显示空白板，月历保留该日期并清空物件预览。

## 8. 时光回顾页面（月历）

### 8.1 页面目标与布局

以日历形式展示每个月的生活记录。首次从首页进入时默认展示设备本地日期所在月份，用户通过日期格上的物件识别当天的记忆。

| 区域 / 功能 | 要求                              |
| ------- | ------------------------------- |
| 顶部导航    | 返回首页，显示当前查看的年份与月份               |
| 月份切换    | 上个月、下个月按钮；可回到当月，P0 不进入未来月份      |
| 星期栏     | 建议从周一到周日排列，采用七列布局               |
| 日期网格    | 完整展示当月所有日期，按实际星期对齐；非当月位置留空，不可点击 |
| 今日标记    | 单独突出今天的日期，与是否有记录区分              |
| 日期内容    | 日期数字 + 当天板面上的前两个物件预览，最多两个       |
| 查看某天    | 点击整个日期格进入该日完整毛毡板，默认浏览模式         |
| 数据刷新    | 从板面返回后刷新相关日期的预览，保留原查看月份         |

P0 用月历承载历史回顾，不再另设历史列表。分类筛选、主题板分组和自动月度回顾仍不在 P0 范围内。

### 8.2 日期格与物件预览

| 当天状态     | 日期格展示           | 点击结果                      |
| -------- | --------------- | ------------------------- |
| 没有物件     | 日期数字，无物件缩略图     | 今天或过去日期进入空白板浏览状态；不因查看创建记录 |
| 只有一个物件   | 日期数字 + 一个物件预览   | 打开完整板面                    |
| 两个及以上物件  | 日期数字 + 前两个物件预览  | 打开完整板面，展示全部物件             |
| 未来日期     | 日期数字弱化，无记录入口    | 不可点击                      |
| 物件图片加载失败 | 日期数字保留，失败图片显示占位 | 仍可打开完整板面                  |

预览规则：

- 使用当天板面中实际存在的物件处理图片，不使用整板缩略图替代两个物件。
- “前两个”暂建议按物件添加到该板的时间从早到晚选取；时间相同时采用固定顺序，保证多次进入结果一致。该排序口径待确认。
- 移动、缩放、旋转或更改层级，不改变月历选取的两个物件。
- 日期格中的图片独立等比适配预览区域，不复制物件在完整板上的坐标与尺寸，不互相遮挡日期数字。
- 日期格中的物件预览只用于识别当天内容，不单独进入记忆详情；点击日期或预览都打开完整毛毡板。
- 超过两个物件时仍仅展示前两个，其余在完整板面中查看，P0 不增加日期格内的轮播。
- 删除预览中的物件后，由剩余物件按同一规则补位；替换图片后刷新对应预览。
- 删除最后一个物件后保留日期格，改为没有物件的状态。

### 8.3 日期点击与返回

- 点击今天或过去有记录的日期：进入对应板的浏览模式，展示全部物件及已保存布局。
- 点击今天的空日期：展示今天的空白板，并保留“记录今天”入口。
- 点击过去的空日期：展示对应日期的空白板与“当天没有记录”提示；P0 不提供补记、编辑或导出入口。
- 点击已有设置但没有物件的历史日期：展示已保存背景和无记录提示，按历史空板处理。
- 查看空日期不创建 Memory、Placement 或新的 Board 记录。
- 从板面返回月历时，恢复原查看月份并刷新对应日期，不能跳回当月。
- 再次从首页进入时默认展示当月。

用户可进入已有历史板编辑或添加记忆；P0 不提供对尚无记录的历史日期补记。

### 8.4 页面状态与月份边界

- **加载中**：保留月份标题、星期与网格框架，显示加载反馈，尚未加载完成的数据不能直接判定为空。
- **当月有记录**：在对应日期显示一至两个物件预览，其余日期正常展示。
- **整月无记录**：仍展示完整日历，并显示“这个月还没有记录”；查看当月时可提供记录今天入口，查看历史月份时提供回到当月入口。
- **加载失败**：保留当前月份并提示重试，不将失败月份误显示为无记录。
- **月份切换**：正确处理跨年、不同月份天数及闰年二月；快速切换后只显示当前选定月份的数据。
- **日期变化**：以设备本地日期更新今日标记与未来日期限制；用户已选定的历史月份不自动跳转。

## 9. 导出流程

入口位于毛毡板浏览模式。

1. 检查当前板面保存状态，未保存成功时先保存或提示重试。
2. 生成包含背景与全部物件的完整图片。
3. 显示导出预览与“保存到相册”。
4. 保存成功后提示结果；失败或权限不足时提供反馈和重试。

导出要求：

- 保持画布构图、物件相对位置、角度与层级一致。
- 不包含页面导航、按钮、控制框、选中工具和保存提示。
- 导出过程中给出进度反馈，防止重复操作。
- 不因单个物件越界而裁掉整块板面；物件超出画布的部分按画布边界裁切。
- P0 空板不提供导出操作。
- 图片格式、分辨率及日期是否绘入作品，在视觉和技术方案阶段确认。

## 10. 通用状态与本地数据提示

### 10.1 状态必须区分

- **加载中**：已有数据正在读取。
- **空状态**：确认没有内容。
- **处理中**：照片正在生成物件。
- **保存中 / 已保存 / 保存失败**：记忆或板面持久化状态。
- **导出中 / 导出成功 / 导出失败**：作品图片生成状态。
- **相册保存成功 / 失败**：图片是否成功写入系统相册。

不得用“导出成功”代替“已保存到相册”，也不得在图片处理完成但尚未持久化时提示“记录已保存”。

### 10.2 本地数据规则

- 第一版不设置登录门槛，不提供云备份与多设备同步。
- 原图、处理图片与结构化记录分开保存。
- 清理临时文件不得删除仍被记忆引用的图片。
- 首次成功保存时展示本地数据提示，日常保存不反复打断用户。
- 文件缺失、空间不足或写入失败时应给出可理解的反馈，并提供可行的重试入口。

建议提示：

> 记录保存在当前设备。卸载小程序或清理相关数据可能导致记录丢失，重要作品建议导出保存。

- [ ] 缩放 / 旋转只作用于选中物件，物件不会完全移出画布。

- [ ] 每个有记录的日期格展示当天板面的前两个物件；一个物件只展示一个，无物件保留日期格。
- [ ] 点击日期格或其中的物件预览均进入该日完整板面，展示全部物件与布局。
- [ ] 查看历史空日期不会创建记录，不提供补记入口；未来日期不可点击。
- [ ] 从板面返回后保留原查看月份，新增、替换、删除后对应预览更新。
- [ ] 跨年、不同月份天数与闰年二月展示正确；切换月份不串用数据。

### 12.2 开发前确认
