- 更新日期：2026-10-13
- 功能依据：[界面功能说明](./界面功能说明.md) V1.2。
- 毛毡板形态：参考图 1 的横向圆角实体展示板，深棕色边框、米色毡面、沿轮廓独立摆放的物件。
- 界面风格：参考图 2 的浅灰绿背景、奶油色纸张、森林绿按钮、柔和投影和手账排版，替换此前以半透明毛玻璃为主的方向。

本文按页面组织可复制提示词，用于界面设计、交互原型和前端生成。浏览与编辑是同一毛毡板页面的两种模式；添加与导出可使用弹层或轻量子流程，不必建立七个独立路由。提示词描述目标效果，不代表主体提取服务已实现。

## 使用方法

生成单个页面时，复制“统一视觉与毛毡板规范”，再复制对应页面的提示词。生成整套界面时，先建立统一规范，再按首页、浏览、编辑、添加、详情、月历、导出的顺序生成。需要修改代码时，最后附加“代码生成补充”。

## 统一视觉与毛毡板规范

```text
请为微信小程序“毛毡生活手账”设计界面。用户上传生活照片，自动提取主体，直接贴到当天毛毡板上，自由布置后保存，并通过月历回顾或导出作品。

【参考图的使用】
图 1 决定毛毡板的实体形态：一块横向的、四角圆润的长方形展示板，四周有连续的深棕色框，内部是完整的暖米色毡面，独立物件像收藏的小作品一样贴在毡面上。
图 2 决定页面的视觉语言：浅灰绿色环境底色，奶油色纸张面板，温和的绿色操作按钮，柔和的落地阴影，纸张颗粒、虚线分隔和少量票据边缘装饰。
把两者组合成“纸质生活手账中的实体毛毡展示板”。页面控件与板体各有材质：外围是纸张，核心展示区域是有边框的毡板。

【毛毡板结构】
1. 板体正面朝向用户，以平面展示为主，保持横向矩形。建议外框宽高比为 3:2，作为本轮设计基准，集中配置；首页预览、浏览、编辑及导出必须一致。竖屏页面完整容纳横向板，周围留白，不拉伸成竖向卡片。
2. 深胡桃棕色框连续围住四条边，内外角均圆润。以手机上约 350 宽的板体为例，可先采用约 8–12 的可见框宽，外圆角约 18–24；缩略图和导出按整体比例缩放。
3. 框体有轻微厚度、低强度高光和内侧阴影，表现实体边缘。避免夸张木纹、雕花或金属光泽，保持参考图中朴素的深色框感。
4. 内侧毡面是暖米色或燕麦色，带均匀、细密、低对比度的短纤维质感。毡面连成一整块，不能分割成网格、照片槽或独立卡片。框与毡面的交界清楚，内沿有轻微凹入感。
5. 整块板在外围背景上投下柔和阴影，表现被托起或挂起的实体感。产品页面使用正视图，不复制照片中的墙面、拍摄透视和室内陈设。

【板上物件】
上传照片提取后的物件保留真实主体形状和透明背景，沿轮廓独立贴附在毡面上，底下有很薄的接触阴影，必要时加细窄暖白边缘。阴影要表现贴附感，避免悬浮很高。
参考图 1 的摆放关系：物件大小有差异、方向可略有变化、间距自然，可以形成松散分组；既能稀疏摆放，也能逐渐收集成丰富板面。不要求填满板面，不自动重排用户布局。
照片主体不能统一装进白色矩形照片卡。不要添加与物件无关的图钉、夹子、连接线或标签框。
保留用户照片的真实视觉，不自动改成拼豆、像素画、卡通刺绣或毛毡玩偶。图 1 的作品只用于说明物件是独立轮廓，艺术风格转换不属于首版。
编辑坐标以内部毡面为基准，外框是固定装饰。主体显示区域限制在毡面内，移动、缩放、旋转均检查变换后的边界，避免压住框体。窄屏只缩放整块板的展示，不改变内部构图。

【外围页面样式】
建议色值：页面背景 #E8EDE7；纸张 #F7F2E9；主文字 #302F2B；辅助文字 #73746D；主按钮森林绿 #4D7D5B；辅助鼠尾草绿 #8FAE92；少量芥末黄 #C9A64B；板框 #493527；默认毡面 #D9CBAF。
颜色依据参考图估拟，可小幅调整以保证可读性。黄色只用于少量强调，如今天标记，不做满屏高饱和装饰。
纸面主体接近不透明，带非常轻的颗粒或点状纸纹；使用浅奶油描边、柔和下投影和适度圆角。虚线用于章节分隔，波浪或半圆票据边缘只在少量内容区使用。
主按钮采用森林绿实色、奶油白文字和轻微深色下沿，表现可按压的实体感。次级按钮用纸白或浅绿色，危险操作低强调并有确认。
标题可使用适合中文的宋体或衬线字形，体现手账气质；正文、日期和按钮使用清晰的无衬线字体。字体不可用时回退到系统字体，正文可读性优先。
标题约 24–28，区域标题 18–20，正文 14–16，辅助文字 12–13。页面留白约 20–24，纸面圆角约 24–28。图标统一为简洁线性图标，主要操作有效点击区域约 44 × 44。
背景可有少量浅绿色弧线或植物笔触，低对比度、远离正文与板面。纸张颗粒、背景笔触和票据装饰均不能覆盖照片主体。
界面以温暖、安静、朴素为主，不以大面积透明玻璃、背景模糊、霓虹渐变或发光效果建立层级。

【统一约束】
以 390 × 844 的手机竖屏为基准，适配 320–430 宽度和小程序安全区域。页面可纵向滚动，不挤压横向板体，也不复制手机外框、状态栏和微信胶囊。
首页、浏览、编辑、详情、月历和导出共用同一组原图与透明主体素材。示例可以使用咖啡、可颂、花束、书本、猫等生活物件，素材缺失时使用可替换图片占位。
不照搬参考图的 ParkLog 品牌、公园信息、12/63 计数、地球图标、打卡按钮或 Designed in variant 标记。应用内文案采用中文。
首版只实现记录、布置、回顾与导出，沿用现有功能约定，不新增社区、商城、账号、主题板、云同步或艺术风格转换入口。
```

## 首页 今天

```text
请沿用“统一视觉与毛毡板规范”，生成“毛毡生活手账”的首页「今天」。

页面像一本打开的生活手账，以今日毛毡板为视觉中心。页面背景为浅灰绿，信息区域为奶油纸面，主操作使用森林绿。

从上到下布局：
1. 顶部留出小程序安全区域。左侧用简洁奶油色圆角标签放产品名或小图标，显示今天日期与标题“把今天，轻轻收好”。右侧如需提示，仅显示真实的今日记忆数量，不使用进度分母或打卡统计。
2. 主体完整展示一块横向 3:2 的实体毛毡板：连续深棕圆角框、暖米色细纤维毡面、贴附其上的独立照片主体。外框四边完整可见，不把板裁成竖向卡片，也不把板放进多重厚重容器。
3. 有记录时展示咖啡、花束、可颂等几件大小不同的透明主体，保持自然间距和轻薄接触阴影。空板时保留完整框体与毡面，仅在板下给简短引导。
4. 板下用轻量文字显示记忆数量与“查看整板”入口，再放一个森林绿主按钮：空板为“记录今天”，已有物件为“继续布置”。
5. 下方用一块简洁的奶油纸张区域展示最近几天的完整板面缩略图与日期；可用虚线分隔标题，区域一侧提供“月历回顾”。缩略图仍保留深棕边框和横向比例。

交互：点击板或查看整板进入今天的浏览模式；继续布置进入今天的编辑模式；记录今天选择照片，自动提取成功后直接放到今天的原板并选中。
点击最近日期进入对应完整板面。月历入口进入当月日历。

补齐今日空板、已有记录、没有历史、加载中和加载失败状态。日期以设备本地日期为准；仅展示空板不创建永久记录。加载失败提供重试，不误显示为空板。首次成功记录后说明记录保存在当前设备。
页面重点是日期、今日作品与主操作。装饰只出现在外围背景和纸面边缘，不能盖住毡板，不增加功能宫格、广告或统计仪表盘。
```

## 毛毡板页面 浏览模式

```text
请沿用统一规范，生成某一天毛毡板的浏览模式，强调完整欣赏一块真实的生活收藏展示板。

顶部用轻量奶油纸色导航承载返回、所属日期和“编辑”。页面背景是浅灰绿，可在远离板面处放极淡绿色笔触。
中间完整展示横向 3:2 的毛毡板，四周连续深胡桃棕圆角框，内部暖米色短纤维毡面。框内每个记忆都是沿真实主体轮廓贴附的独立物件，有不同大小、轻微角度与薄接触阴影。
构图沿用首页和持久化数据，不重新排布。板体完整适配宽度，允许上下留白，不能为了占满手机高度改变板体比例。板外可显示日期与记忆数量，不把这些文字印到毡面上。
底部用简洁的纸色操作区域或森林绿按钮提供“导出这一天”。导航、说明和操作区不遮挡板体。

浏览时不显示选中框、四角按钮、删除、拍照或相册工具。点击物件打开对应记忆详情；拖动和轻微滑动不改变布局。
点击编辑切换到同一板面的编辑模式，板体比例与物件位置保持一致。从详情返回恢复所属日期和浏览模式。

有记录时展示全部物件。今日空板保留完整实体板并提供记录入口；过去空日期显示“当天没有记录”，保留空板但不创建数据，不提供补记、编辑或导出。仅有设置而无物件的历史板按既有功能规则展示。
补齐加载中、加载失败与重试。所有状态使用同一材质，不用模糊蒙层代替正常板面。
```

## 毛毡板页面 编辑模式

```text
请沿用统一规范，生成毛毡板编辑模式。编辑是在一块固定的实体展示板上摆放独立记忆物件，板框本身不可编辑。

布局：
- 顶部为返回、所属日期、保存状态和“完成”。使用奶油纸面和清晰绿色强调。
- 中部是完整横向 3:2 毛毡板，深棕圆角框与米色毡面同浏览模式，模式切换时不改变板体构图。
- 底部是奶油色圆角工具条，包含拍照、相册、板面设置，配简洁绿色图标和文字。
- 选中物件时，板下可显示物件名称、只读尺寸或角度反馈，以及“查看 / 写下记忆”“删除记忆”。

选中与变换：
1. 点击独立主体图片后显示细选中框。左上是逆时针，右上是顺时针，左下是缩小，右下是放大。
2. 四个按钮使用奶油白或浅绿色实体圆形按钮、深绿图标和轻投影，与纸张界面一致。默认不以毛玻璃模糊作为材质。
3. 单击缩放按钮按建议约 10% 的步长调整；旋转按建议约 15° 的步长调整，数值集中配置。无需滑杆或双指手势。
4. 按钮只操作当前物件，图标保持正向。点击按钮不触发拖动或记忆详情。
5. 拖动选中物件改变位置；点击毡面空白取消选中。物件本身限制在内部毡面，不能覆盖固定框体或完全移出板面。
6. 四角操作控件属于界面覆盖层，不属于物件或作品。靠近边缘时可向可见区域调整位置，保留有效点击区域，不能被板内裁剪层裁掉或互相重叠；保持与选中物件的视觉关联。
7. 添加只插入新物件，不自动移动、缩放或挤开原有物件。重叠时选中最上层命中的物件。

板面设置使用奶油纸色底部弹层，首版提供少量基础毡面颜色，如默认燕麦米、浅鼠尾草绿、浅暖灰；深棕边框固定，所有颜色保留低对比度纤维质感。更多纹理和边框换肤不在首版范围。
拖动结束、每次缩放 / 旋转和设置变更后自动保存，显示“保存中…”“已保存”或“保存失败，请重试”。完成保存成功后回浏览模式，失败保留编辑内容。离开时有未保存内容应提供重试或确认放弃未保存部分。
删除使用确认弹窗，说明应用内照片、文字与板上物件一并删除，不影响系统相册原图。

展示未选中、选中、旋转放大、新物件刚插入、设置弹层、保存失败和删除确认状态。不添加底部大小 / 角度滑杆、通用撤销、手动图层排序或批量选择。
```

## 添加记忆流程

```text
请沿用统一规范，生成“拍照 / 相册 → 自动提取主体 → 原板插入并选中”的添加记忆流程。它是毛毡板页面上的子流程，保留原板上下文。

照片来源用奶油纸色底部弹层承载，绿色线性图标分别表示拍照与相册，每次添加一张。确认照片后上传并自动提取主体，不跳转独立美化向导，不要求先填文字或分类。
背景中的原板保持完整的深棕框、米色毡面与原有物件。必要时压暗背景强调处理面板，但不要给板上照片加模糊。处理面板采用接近不透明的奶油纸面、浅色描边、柔和投影与绿色进度提示。
面板可展示原图与主体结果的对应位置，箭头或简洁文字表示处理关系。结果未返回前使用占位，不能提前伪造已完成的提取结果。

状态与响应：
- 上传中：显示“正在上传照片”，允许取消，防止重复提交。
- 上传失败：重试上传或取消。
- 自动提取中：显示“正在提取照片主体”，保留原板，允许取消。
- 提取失败：显示明确失败原因或可理解提示，提供“重新提取”“使用原图继续”“取消”。
- 保存中 / 保存失败：与提取状态区分；失败保留已取得的结果，允许重试保存，不重新要求选图。
- 提取与保存成功：自动关闭浮层，主体直接贴到发起流程的原板内部毡面，位于最上层并自动选中，立即显示四角缩放与旋转按钮。

主体保留照片真实形状、透明背景、细窄边缘与薄接触阴影，不转成像素拼豆、卡通或毛毡玩偶。若用户选择使用原图，则明确保留矩形原图作为失败降级；不能提示为抠图成功。
新物件采用适合板内区域的默认大小和位置，已有物件不改变。原图与主体图分别保存，文字默认空、分类默认未分类，可在插入后进入详情补充。
不增加“生成贴纸”“下一步”“放到毛毡板”等成功后的插入确认步骤。

流程开始时固定目标 Board 与日期，历史板发起仍写回那天，跨零点不改目标；取消或离开后过期回调不能继续插入。Memory 与默认 Placement 一并保存，成功只插入一个物件。
真实提取服务未接入时，用明确匹配的示例原图和透明主体演示状态，在交付说明标识演示能力，不用 CSS 裁剪冒充提取。
```

## 记忆详情页面

```text
请沿用统一规范，生成记忆详情及内容编辑状态。页面像手账中的一页记录，以原始照片和用户文字为重点。

顶部为返回、标题“这一刻”和编辑入口。浅灰绿页面上放奶油色纸面内容区，可用细虚线分隔照片、正文和元信息；票据或半圆纸边只选择一处轻量使用。
上方展示清晰的原始照片，保持原始宽高关系或使用可查看完整照片的适配方式。下方以小面积米色毡面样本承托透明主体预览，延续物件贴在毡面上的感觉；预览是同一条记忆的处理图。
正文使用易读无衬线字体，区域标题可用宋体。日期、分类以小标签展示，颜色使用浅绿或纸白。文字为空时显示“写下记忆”入口，不编造用户内容。
```
