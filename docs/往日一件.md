# 往日一件

2026-10-30：首页日历板停在「今天」且没有正在进行的操作时，左下角显示一张贴近纸页下沿的暖米色圆角卡片。卡片带轻微纸纹，白色粗虚线沿物体外轮廓环绕，标题「往日一件」收在下方，天数在点开后展示；卡片避开中间的添加操作。

轮廓通过 96 × 96 的离屏缩略采样生成并缓存，描绘外部边界，不描内部孔洞。透明留白较多的图片会按可见范围适配；不支持像素读取时回退到沿图片边缘的圆角虚线。采样和缝线用于角卡及回顾展示，不修改照片文件或导出的板面。

## 显示与切换

- 长按进入布置、选中物体、拖动、缩放或旋转时隐藏。点板面空白处结束布置，保存成功后恢复，并换一件。
- 从打开「添加记忆」、选图、处理到落到板面期间隐藏；完成或取消后恢复。保存失败时继续隐藏。
- 菜单、记忆详情、分享、日期选择等面板打开时暂停；历史日期和主题板不显示角卡。
- 进入或回到今日首页、从后台回来、结束编辑或添加时更换物件。停留在首页且没有操作时，每 45 秒更换一次；手指按住和应用进入后台时暂停。
- 回顾面板打开时固定当前物件，关闭后保留刚才看的物件，重新计时 45 秒。只有一件候选时保留它，没有候选时不显示角卡。

## 查看和恢复

点击角卡，从屏幕底部打开回顾面板，展示物体、原始日期和已有文字。「再看一件」手动切换；「查看那天」收起回顾面板，直接切换到该物体所属日期的日历板，顶部日期、日期栏与板面同步更新，可以继续使用日历板的查看、编辑、补记和分享操作。「回到今天」返回今日板。普通关闭回顾面板时，原有日期和布局保持不变。

「不再回顾这件」仅加入回顾隐藏列表，不删除照片、文字或摆放。日历板「更多 → 往日一件」始终提供入口，可恢复全部已隐藏的物件，包括全部隐藏、首页没有角卡的情况。

回顾沿用现有底部面板的进出动效；查看那天时，面板收起后沿用日历板的日期切换。原生 Canvas 在面板遮挡时冻结，避免穿透。

展开页使用暖色纸纹展示区和白色随形缝线，日期与原文分层展示，底部「再看一件」「查看那天」固定，长文字在按钮上方滚动。

首页空闲时提前生成并解码当前物件展示图，同时准备当前板面的遮罩截图。点击时复用已准备好的画面，省去即时重绘、导出及描边计算。板面内容或画布尺寸改变后，旧截图不再复用；触摸、编辑、后台和关闭过程中取消待处理的准备任务。尚未准备好展示图时先显示原图，等开场动画结束后再生成缝线，避免与进场动画争抢绘制。

## 选取规则与数据

从已有记忆中按记忆 ID 选取，日期必须早于今天，并有可读取的物体图片。同一记忆即使摆在多个主题板上也只算一件。排除隐藏项和本次无法读取图片的项。

优先选取不在最近展示记录中的物件，其中优先七天以前的记忆；如果都在最近记录中，则选择最久没展示的。多件候选时排除当前物件，只有一件时允许继续展示。最近记录最多保留 100 个 ID，隐藏偏好和最近记录保存在独立的本地键 `felt-journal:recall:v1` 中，不修改原始手账数据，也不上传或同步。

角卡属于界面绘制层，不是当天板面的摆放，导出和分享图片不会包含它。

## 验证

```powershell
npm test
npm run check
./scripts/compile-wechat.ps1
npm run test:recall
```

`test:recall` 需要连接空闲的微信开发者工具自动化端口（默认 `ws://127.0.0.1:9420`）。使用本地生成的示例物体，临时隔离五个存储键，结束时核对原始存储完全恢复，并清理示例图片。期间不要并行运行其他模拟器测试、操作小程序或重新编译。截图和验收结果只保存在忽略的 `artifacts/memory-recall/`，不提交用户数据。

已覆盖真实等待 45 秒后的轮换、角卡与添加按钮不重叠、查看那天直达对应日历板并返回今天、编辑及图片处理时隐藏、只在今日日历板显示、全部隐藏后从更多恢复，以及源手账数据保持不变。自动测试另覆盖按住暂停、后台恢复、单候选、跨日计算、无效日期、关闭期间重复点击、图片失败、偏好保存失败和编辑保存失败。

性能回归使用不同图片路径，验证当前物件和板面在点击前已准备好，并记录打开前的准备耗时到 `artifacts/memory-recall/opening-timing.json`。单元测试覆盖缓存失效、延迟回调取消、开场动画期间暂停准备，以及命中缓存时不重新加载、绘制或导出板面。模拟器计时不代表手机帧率。

物理手机的小屏布局、系统大字体、切后台与原生画布动效仍需真机体验确认；当前结果不等同于已经发布体验版或正式版。
