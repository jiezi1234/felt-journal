# 独立记忆库

记忆库是可命名的收藏夹，与日历板、主题板独立。同一个物体可以加入多个库；图片和文字仍为同一份，不复制照片，也不改变任何板面的摆放。

## 入口与操作

- 日历板的分享图标旁新增「更多」，内含「版面和纹理」「记忆库」。主题板的「更多」同步提供这两个入口，并保留分享、重命名和删除主题板。两种模式共用记忆库，关闭后仍停留在原来的日期或主题板。版面和纹理沿用当前板面的颜色、纹理与自动保存逻辑。
- 记录照片处理完成后，点击「同时加入记忆库 · 选填」，可新建并选择一个或多个库。保存选择后回到照片结果，仍需点击「开始布置」才会放到板上；直接关闭不会自动摆放。已经保存的照片及收藏关系继续保留。
- 日历板、主题板及记忆库里的物体都使用同一张物体卡片。卡片顶栏提供「加入记忆库」，已经归档时显示库的数量。选择器预选已有归属，取消不改动，保存后一次性更新。
- 记忆库卡片先显示「全部物体」与自定义库的缩略图、名称和数量。点击库后，在原卡片内陈列该库物体。点击物体打开详情，再次点击图片翻面查看文字；关闭详情回到原库，并保留滚动位置。
- 库内支持文字、日期和分类搜索，物体按最近记录在前排列，每次加载 30 件，可继续滚动或点击加载。每个库可重命名、删除；删除库只取消该收藏夹，不删除照片、文字或板面摆放。
- 新建或重命名限制 1–30 个字，最多 100 个库，同名库会给出提示。未归档的物体仍可在「全部物体」找到。

## 存储与弹层

沿用现有本地存储键及 v2 快照，新增可选 `libraries` 字段。旧快照读取不写入，第一次创建库时才增加该字段。归属修改与原数据在同一次原子写入中保存，写入失败保留原状态。替换照片保留收藏关系，彻底删除物体时清理库内引用；旧客户端留下的失效引用不计入展示数量。

浏览库与查看物体分开挂载，详情关闭后恢复原库。选择器放在记录/物体卡片的根级，避开卡片的裁切和变换。库与菜单打开期间隐藏原生毛毡画布，防止画布覆盖弹层；底层模式切换、手势和重复放置同时锁定。

## 验证

`npm test`、`npm run check`、`scripts/compile-wechat.ps1`；专项原生 UI 验收为 `npm run test:libraries`。

开发者工具自动化连接超时时，先重新打开项目并等待首页加载完毕再运行。若截图接口超时，可使用 `npm run test:libraries -- --no-screenshots` 跳过截图，所有原生交互、布局边界和存储断言仍会执行。

2026-10-26 验证：391 项自动测试、91 个 JS/JSON 文件与 9 个路由检查、27 个 WXML 与 21 个 WXSS 官方编译通过。430 × 932 开发者工具窗口的专项交互验收通过，包含长文字摘要、卡片内按钮边界、主题板更多菜单进入共用记忆库、翻面查看后返回原板；全部测试存储恢复一致。

专项使用自带图标构造独立数据，覆盖更多菜单、纹理保存、库内浏览、翻面、多个归属、取消、创建、分页、详情返回位置以及照片结果归档后取消摆放。完成照片结果使用受控快照，提取及持久化过程由现有 PhotoTask 测试覆盖。测试结束（包括失败）逐项恢复原存储；日志、截图及临时备份只留在被忽略的 `artifacts/memory-library/`。运行期间不要同时操作或重新编译开发者工具。手机真机触摸、系统键盘及大字体布局仍需设备验收。
