# 顶部板面切换

首页采用「侧边书签」布局：右侧书签默认收起，只露出窄把手；第一次点击展开并显示当前「日历板 / 主题板」，展开后再次点击才切换整理方式。顶部使用自定义导航，日历模式显示日期，主题模式显示「我的收藏」，按真实状态栏和微信胶囊位置留出安全区域；移除原来的独立模式标题和说明行。原有 tab 路由保留兼容性，custom-tab-bar 不再绘制底部导航入口。

- 日期／主题栏统一压缩至 64px（矮屏 60px），仍展示五个日期或三个主题与「更多」，两种模式占用相同高度。
- 收起时把手视觉宽度 18px、高度 64px，保留 44px 宽的原生触摸与无障碍点击区域；展开后宽度 44px，普通板高 132px，短板高 112px。展开使用原生画布渐变，不改变毛毡板尺寸，不修改布局、选择对象或浏览日期。切换完成后保持展开，每次点击切换按钮重新计时，连续 3 秒没有点击才自动收起；触碰板面其他位置、点顶部空白或打开菜单时仍可立即收起。离开页面会清除计时器。
- 书签的绘制、原生画布命中和无障碍按钮共用一份位置。拖动、落板、弹层和处理照片时隐藏，禁用时不触发切换；两次独立点击完成展开和切换，同一次手势的重复事件不会误切，也不会打开背后的照片。书签与底部添加按钮均属于界面，不进入分享图片。
- 没有任何主题板时保留可点击书签，仍可返回日历板。顶部日期与「我的收藏」不会挤占微信系统胶囊。

- 日历板首次显示今天。主题板首次使用本地记住的主题；该主题不存在时，选择最近更新的主题。
- 本次使用中分别保留浏览的日期与主题。正在查看今天时跨日会跟随到新一天；正在查看历史日期时保持原日期。记录卡片、照片处理及分享未结束时锁定当前板面。
- 日期栏显示选中日期附近的五天，右侧「更多」打开月历卡片。选日直接切换主板，不再叠加每日板卡片。未来日期不可选，空白历史日期可补记，浏览本身不会创建空板。
- 主题栏显示三块主题及其名称、最新加入该板的物体缩略图。「更多」打开全部主题及新建入口。主题顺序按创建时间保持稳定，点选不会重新排序。
- 月历日期格与主题选择卡片均展示最多两件物体，按加入板面的时间选取；不足两件时按实际数量显示。缩略图加载后依次渐显，月份及主题卡片进入时有轻微位移动画。
- 两种模式的标题操作区固定预留 48px，日期、主题、空板及有无分享按钮都使用相同的板面宽高与位置。主板切换使用 240ms 原生画布渐变，板框保持原位，避免普通透明度动画被原生画布穿透。连续切换会取消上一段动画并显示最新选择；动画期间不响应板上手势，结束后恢复。选择卡片渐入，关闭时保留 180ms 退场动画，再解除板面遮挡。
- 点击「更多」时先预载可显示的板面静态画面，再挂载选择卡片；卡片存在的整个期间（含退场）直接隐藏原生画布，不依赖画布帧回调或弹层层级。预载失败也保持画布隐藏，离开页面或取消准备后不会延迟弹出卡片。
- 最新缩略图依据板内 placement.createdAt 确定，同一时间按数组中的后一个摆放确定；不按照片原始日期或图层顺序选取。替换图片、移除物体后同步更新。
- 切换前保存待保存的布局；保存失败时停留原板。分享、记录、恢复草稿、拖动及其他弹层会阻止后台切换。
- 毛毡板延伸到屏幕底部附近，「添加记忆」悬浮于板面下方并避开底部安全区；历史日期显示「补记这一天」。悬浮层空白处允许板面触摸穿透，拖动、缩放、旋转及物件落板时暂时隐藏，结束后恢复，不改变板面尺寸。主题板继续支持拍照、相册、记忆库、重命名、删除、纹理与分享。

验证入口：`npm test`、`npm run check`、`scripts/compile-wechat.ps1`、`npm run test:navigation`。

导航验收使用独立示例数据，覆盖书签两次点击、点击外部收起、空主题入口、模式记忆、最新缩略图、记忆库放入、分享、空白日期补记及六周月历，并在结束后恢复原有存储和主题偏好。可加 `--bookmark-screenshots` 保存书签收起与展开的截图。截图、日志、存储备份仅保存在被忽略的 `artifacts/journal-navigation/`，不提交到仓库。
