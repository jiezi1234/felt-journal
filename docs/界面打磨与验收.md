## 第一轮及手柄修复

- 缩放、旋转和移动预览按 Canvas 帧合并绘制；松手使用最后触点，手指替换或取消时放弃预览。
- 三个手柄跟随贴纸原来的角点旋转；靠边时将整个控制框约束到板内，保留三个独立的 44px 触控目标，避免按外接矩形反复换位。
- 揭起 420ms、停留 80ms、飞行 620ms、落地 80ms，固定阶段合计 1.2 秒；保留实际落点就绪等待及失败兜底。
- 原图对比后继续时恢复并测量保存的主体；键盘展开时继续，会先收起键盘并等待图片布局恢复，再测量落板动画起点。
- 四类弹窗共用遮罩淡入、卡片上移和 180ms 退出；退出结束后卸载，内层关闭保留外层日期板。
- 弹窗使用可见视口高度和底部安全区，键盘已缩小视口时不重复扣减；说明输入与主按钮保留在可见区域。

- `npm test`：245 项通过，包括手柄跨象限、窄板边缘连续性、保存失败重试、引导持久化与键盘恢复后测量。
- `npm run check`：72 个 JS/JSON 文件和 9 个页面路由通过。
- `scripts/compile-wechat.ps1`：24 个 WXML 模板、20 个 WXSS 样式经微信官方编译器通过。
- `npm run test:controls`：今天、主题板、历史板的 Canvas 和覆盖按钮连续缩放旋转、松手保存、取消恢复、重复点击抑制通过；同时检查 Canvas 与 DOM 手柄中心一致，原有存储保持不变。
- `npm run test:round1`：320px 模拟器的选图、结果操作、键盘布局、短落板动效、分享、日期板及嵌套关闭通过。
- `npm run test:round2`：320px 模拟器的导航层级、引导收起及重开、保存失败重试、处理到结果的预览位置、主次按钮及统一关闭控件通过；截图已检查，原有记录存储保持不变。

模拟器图片处理状态使用隔离样例和已完成结果，不调用公网主体提取；键盘高度通过已注册的展示处理器注入。测试及截图在忽略的 `artifacts/round1`、`artifacts/round2` 中生成，临时诊断和用户照片不进入版本库。

清单第 9–12 项（月历状态、分享成品专项、减少动效、整体材质规范）不在本次第二轮范围内。

## 毛毡板实体质感

2026-10-20：根据新增反馈，在共享 Canvas 渲染中加入顶部哑光金属夹和物件钉帽，同时细化木框与毡面。

- 金属夹有折弯线柄、拉丝面、铆钉、压口和接触阴影，位于框顶中央。
- 木框采用暖木色渐变、细木纹、倒角高光和内侧暗槽；圆角外保持透明，与页面自然衔接。
- 毡面增加固定坐标的短纤维和压边明暗，换色、换纹理延续现有材质选择。
- 钉帽根据照片透明度选择上部可见区域，避免落在主体外的透明留白；随物件移动和旋转，反光方向保持一致。
- 静态材质底图按画布尺寸、颜色和纹理缓存，拖动只重绘物件、钉帽和手柄；不支持离屏画布时使用直接绘制。
- 浏览、卡片快照和导出调用同一套渲染，阴影按输出像素比例缩放。五金属于展示层，原图和摆放仍沿用现有数据。

本次验证：247 项自动测试、73 个 JS/JSON 文件、24 个 WXML 和 20 个 WXSS 官方编译通过；288/320/390/430/1800px 渲染及 18 种颜色/纹理组合检查通过。430px 微信模拟器的今天、主题板、历史板连续缩放旋转，以及落板、键盘布局、分享和日期卡嵌套回归通过，原有记录存储保持不变。透明区域定位、材质缓存失效和缓存／直接绘制一致性均有专项检查。

示例效果在本地 `artifacts/board-material`，模拟器 Canvas 输出在 `artifacts/board-controls`；均为隔离的示例物件。
